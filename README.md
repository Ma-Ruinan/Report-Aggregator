# Report Aggregator

将多份测评子报告整合为一份统一的综合测评报告的可复用 skill。适用于「多份测评子报告（各自关注不同能力维度）→ 一份综合报告」的任务。

## 用途

测评任务通常拆分为多个能力维度（如常规能力、系统性能、深度洞察、数据分析、安全防护），每个维度产出一份子报告。本 skill 沉淀「如何把这些子报告整合成一份高质量综合报告」的方法，使组内成员无需重复口述要求即可独立完成汇总。

## 安装

将本仓库安装为 skill，安装后位于 `~/.workbuddy/skills/report-aggregator/`，`references/` 目录随 skill 一并就位，无需额外拷贝。

## 使用

安装后，对 AI 说明「帮我把这几份子报告整合成一份综合测评报告」，并附上子报告文件。AI 加载 skill 后会自动读取全部参考文件，先向使用者确认任务信息（受测对象、能力维度、口径约定等），再按五阶段流程执行，最终交付综合报告并附自检结论与待人工判断项。

也可不借助 AI，直接阅读 `SKILL.md` 与 `references/` 下的文档，按流程与自检清单人工执行。

## 目录

```
report-aggregator/
├── SKILL.md                    # 入口：核心原则、五阶段流程、硬性红线
├── references/
│   ├── 方法论.md                # 五阶段详细方法论
│   ├── 自检清单.md              # 数值/逻辑/表述/图表/口径五类自检
│   ├── 报告骨架模板.md          # 综合报告通用章节骨架
│   ├── 风格参考报告示例.pdf     # 版式范本（仅作风格参照，不引用其数据）
│   └── worked-example.md       # 一次真实汇总案例
└── README.md
```

## 前置条件

文档处理能力（提取 docx/PDF 文本与图片、生成 Word/PDF）由使用者环境自行提供，如 WorkBuddy 内置的文档处理插件或自行安装 `python-docx`、`pymupdf` 等。该部分属于运行环境依赖，不随本 skill 打包。

## 核心原则

数值忠实不编造；口径诚实不强行合成；图表能留则留；判断权交还制作人；强制自检；表述可读。

## 适用范围

限于测评/测试任务内的「多份子报告 → 一份综合报告」。与测评无关的多文档合并任务不适用。
